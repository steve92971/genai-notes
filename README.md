# 📒 生成式 AI 小白筆記

TAICA「生成式 AI：文字與圖像生成的原理與實務」（115-1）的每週上課重點，用白話寫給初學者。

- 網站：https://steve92971.github.io/genai-notes/
- 專案規則：[AGENTS.md](AGENTS.md)（給 AI 看的開發說明書）

## 新增一週筆記
對 AI 說「新增第 N 週筆記，內容是……」，AI 會依 AGENTS.md：
1. 複製 `notes/_template.md` 成 `notes/weekNN.md`
2. 照範本格式寫內容
3. 在 `notes/index.json` 加一筆

網站的側欄和首頁卡片會自動出現新的一週，不用改其他檔案。
