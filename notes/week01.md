## 2️⃣ 為什麼要學「原理」？（本週核心觀念）

老師說學 AI 常有三種焦慮：

| 焦慮 | 老師的回答 |
|---|---|
| 😰 我會不會被 AI 取代？ | 會取代你的，是「會用 AI 的人」。 |
| 😵 新工具每天出，到底要學哪個？ | 懂原理就會發現，各家大型語言模型的基礎其實差不多。 |
| 🤯 學 AI 好難啊… | Prompt、AI Agent 這些新名詞，其實都只是「**教 AI 做事的方法**」。 |

### 🤖 「呆萌型 AI 機器人」
這是整門課最重要的比喻：

> 現代 AI 模型就像一個**呆萌的機器人**：不會分析、沒有意識、不知道自己在做什麼。
> 它只會做一件事：**給它輸入，它吐出輸出**。我們要告訴它輸入是什麼、輸出是什麼。

**例子：八哥辨識**
- 輸入：一張八哥的照片
- 輸出：其實是 **3 個數字**，分別代表「土八哥、白尾八哥、家八哥」的可能性
- 中間那個「機器」就是一個 **函數** $f_\theta$

**生成式 AI 也是一樣的呆萌機器人**：
- 圖像生成：輸入文字（prompt）「戴兔耳帽的兔子」→ 輸出一張圖
- 文字生成：輸入「請列出五個學 AI 的重點」→ 輸出一段文字

💡 **小白重點**：AI ＝ 一個很大很複雜的「函數」。這也是為什麼第一週作業要你「畫函數」，先熟悉什麼是函數！

### 為什麼要研究生成式 AI？

## 3️⃣ Colab 入門（寫作業一定要會）

### Colab 是什麼？
- Google 的 **雲端寫程式工具**，用 Chrome 打開網頁就能用。
- **不用安裝**任何東西，用 Google 帳號登入就好，還能**免費用 GPU**（跑 AI 很需要）。
- 它是「雲端版的 **Jupyter Notebook**」：一頁裡可以同時放 **程式碼** 和 **筆記文字**。

### 基本操作
| 我想要… | 怎麼做 |
|---|---|
| 開新筆記本 | 到 colab.research.google.com →「新增筆記本」，或在雲端硬碟「新增 → Colab」 |
| 開老師的程式 | 開啟筆記本時選 **GitHub** 分頁，輸入 `yenlung` |
| 存一份自己的 | 打開別人的程式後，**檔案 → 在雲端硬碟中儲存副本** |
| **執行一格程式** | 按 **`Shift + Enter`**（最重要！） |
| 開 GPU | 編輯 → 筆記本設定 → 選 GPU |
| 查指令說明 | 指令打一半按 **`Shift + Tab`** |
| 自動補完 | 按 **`Tab`**（打 `\pi` 再按 Tab 會變成 π） |
| 療癒小彩蛋 | 工具 → 設定 → 其他：勾選「柯基模式、貓咪模式、螃蟹模式」🐶🐱🦀 |

📌 老師建議：工具 → 設定 → 編輯器，把「縮排寬度」改成 **4**。

### 「格子」有兩種
- **程式碼格（Code）**：寫 Python，執行後下面會出現結果。
- **文字格（Markdown）**：寫筆記、標題、數學公式。
- 切換快捷鍵：`Ctrl + M` 再按 `M` → 變文字格；`Ctrl + M` 再按 `Y` → 變回程式格。

## 5️⃣ Python 畫圖（第一週作業的內容）

### 老師的「固定 4 行」⚠️ 作業一定要放，沒放總分 -1
```python
%matplotlib inline               # 讓圖直接顯示在網頁上
import numpy as np               # 數學計算工具
import pandas as pd              # 表格資料工具
import matplotlib.pyplot as plt  # 畫圖工具
```

> `%` 開頭的叫「魔術指令」，是 Jupyter／Colab 專用的特殊指令。

### 畫圖王牌指令：`plt.plot`
```python
plt.plot([3, -5, 7, 2])
```
→ 畫出 (0,3)、(1,-5)、(2,7)、(3,2) 四個點，再連起來。

```python
plt.plot(X, Y)   # X 是所有點的 x 座標，Y 是所有點的 y 座標
```

### 描點法畫函數 ⭐
電腦其實**不會畫曲線**，只會「畫很多點再連起來」。點夠密，看起來就是平滑曲線：
```python
x = np.linspace(-5, 5, 1000)   # 在 -5 到 5 之間平均取 1000 個點
y = np.sin(x)                  # 算出每個點的 y
plt.plot(x, y)                 # 連起來，就是 sin 曲線
```

### zip：把座標「配對」或「拆開」
```python
X = [0.8, 1.2, 2.1, 2.8]
Y = [2, -5, 3.2, 5]
list(zip(X, Y))      # → [(0.8, 2), (1.2, -5), (2.1, 3.2), (2.8, 5)]  配對
X, Y = zip(*points)  # → 反過來拆開（unzip）
```

### 手繪風格
```python
plt.xkcd()   # 讓圖變成可愛的手繪漫畫風
```

### 互動滑桿（進階彩蛋）
```python
from ipywidgets import interact

def draw(n=1):
    x = np.linspace(-5, 5, 1000)
    y = np.sinc(n*x)
    plt.plot(x, y, lw=3)

interact(draw, n=(1., 10.))   # 會出現一個滑桿，拖動就能即時改變圖形！
```
